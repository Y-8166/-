## 登记和命名

- 按接收顺序分配不可重用的 ID：`CASE-0001`、`CASE-0002` 等。
- 案例分析文件采用 `案例记录/CASE-0001-简短标题.md`；允许保存图像时，图片放在 `案例图/CASE-0001-原图.ext`，在该案例的 Markdown 以相对链接引用。
- 来源仅为外部网页时，可记录来源 URL，不一定复制图片。不要在 `01-信息图形数据逻辑/` 放图片。
- 同一案例若同时属于混合型和时间轴型，只创建**一份案例主记录**，在多个类型说明中链接回相同记录，避免统计时重复计数。
- 不修改已有 CASE ID；修订案例分析可更新文件并通过 Git 历史追溯。

## 推荐筛选字段

`type_primary`（mixed / informational-list / timeline / other）、`logic_primary`（chronological / hierarchical / catalog / alphabetical / geographic）、`logic_secondary`、`chart_family`、`visual_symbols`、`narrative_path`、`evidence_status`。
