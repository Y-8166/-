# 11 可视化文本型信息图形（Visualized Text）

> **证据边界**：本说明以用户上传的《第三讲—信息图形类型学(2).pdf》第 32 页作为图像观察来源；课件截图能支持图形构成与版式描述，但未经原始作品/数据验证的作者、数值与效果均不作为事实。

## 课件图例的可见特征

左图以大量品牌名/标志和圆形群组进行视觉聚合，右图围绕“品牌流程”核心词展开环形关系。

## A. 数据逻辑与最小结构

信息单元是`文本词项｜语义关系｜频次/权重(可选)｜解释`；文字既是内容，也是图形元素。

## B. 借用的统计图形与计算方式

只有绑定实际词频或度量时才可用词云、词条面积；流程词图可映射关系但不自动代表数量。

## C. 视觉编码（点、线、面、体、符号、色彩与排版）

字重、字号、色彩、位置和环绕路线组织阅读；大字可能是视觉标题而非统计权重。

## D. 数据／信息架构

核心概念→语义类群→关系链→注释，保留文本原义及字词边界。

## E. 视觉叙事架构

视觉中心提示主题→组群联想→按路径发现关系→返回摘要；兼顾文字可读与视觉节奏。

## 边界与待核实事项

词项尺寸若无图例，不能推断比例；图像右侧看似流程，也可能是概念关系图。

## CASE-0017 词云信息图（Word Cloud Infographic）

> **案例状态：待图像核验。** 用户于 2026-11-23 指定加入“17 词云信息图”，但本轮未附该作品图片、原始语料或词频表。下面是研究用的 A–E **分析框架**，不是对某张具体作品的实证观察。本小节就是 CASE-0017 的案例记录位置，后续原位更新，不新建 `CASE-0017.md`。

### 0. 案例元数据

- 编号：`CASE-0017`；名称：词云信息图 / Word Cloud Infographic。
- 主要表现：可视化文本型；是否兼具混合型、比较型或信息列表型，待具体图片判定。
- 数据逻辑：**编目型（暂定）**，因为词项通常以词频或权重组成可检索集合；若图上有其他真实关系，需据证据重判。
- 图片、作者、作品出处、语料、原始数值与授权：**均待提供／待核实**；目前不放假设性配图。

### A. 基本数据逻辑

词云的数据最小记录可写为：`词项ID | 原始词形 | 规范词形 | 词频 | 权重（可选） | 类别（可选） | 语料来源 | 时间范围`。核心是“词项—出现次数/权重”的对应关系，而不是词语之间自然存在空间距离或层级关系。中文分词、停用词、词形归一、合并同义词、多语言筛选会影响结果，必须说明。

### B. 统计图形与计算方式

- **出现次数** `f(w)`：词语 `w` 在规定语料中出现的次数；**相对频率** `p(w)=f(w)/N`，其中 `N` 为清洗后有效词项总次数。
- 多篇文本可比较文档频数（包含某词的文档数量），也可使用 TF–IDF 等指标；不能把不同口径的词频和权重混为一谈。
- 词项权重通过**单调的字号映射**表达，例如 `size(w)=minSize + k·g(weight(w))`（`g` 可以是线性、对数或平方根，须记录实际选择）。
- 词云适合发现高频词与主要话题，**不适合精确比较词频差值**；如需精确量化，应辅以词频排名表、条形图或表格。
- 词云的字形占据面积还受字数、字体和字宽影响；不能单凭视觉面积反算词频。

### C. 视觉编码：点、线、面、体、符号、色彩

| 视觉要素 | 可能的表达功能 | 核验风险 |
| --- | --- | --- |
| 点 | 词项锚点/聚类中心 | 默认布局位置通常不是统计坐标 |
| 线 | 若有，可能表示语义连接或阅读导向 | 不要将装饰连线推断为计算出的关联度 |
| 面 | 词语占据的面积、留白、外轮廓 | 词长与字号共同影响面积，不等于词频比例 |
| 体 | 可选立体字、透视或浮雕 | 体积效果可能夸大词项重要性 |
| 符号 | 文字本身、可选主题图标与图形容器 | 语义符号不必然具有定量意义 |
| 色彩 | 分类、语料来源或强调（如果图例这样规定） | 任意配色不能冒充统计分组 |
| 字号与朝向 | 核心权重编码、视觉节奏 | 旋转、字体对比影响显著程度和可读性 |

### D. 数据／信息架构

**研究问题和语料范围 → 文本收集与去重 → 分词及停用词过滤 → 词频/权重统计 → 排序和选词 → 字号/颜色/位置布局 → 标注语料和方法 → 可选精准对照图表**。若数据不可追溯，必须标注“词云式视觉排版”，不能宣称统计词云。

### E. 视觉叙事架构

**主题标题 → 最显眼的核心词 → 相关词群 → 次要词与反例 → 结论/局限**。词云通常提供开放式、非线性的扫读，而非必然的时间顺序。设计者可以用层次、颜色和聚类表达话题关联，但应提供语义依据，不把词语靠近直接解释为真实相关性。

### 后续案例图分析及改动规则

1. 收到词云原图后，在本小节补入可见词项、字号、位置、颜色、布局形态、视觉焦点、作者和实际来源；**目前暂无图片，不捏造观察结果**。
2. 获取语料和统计方法后再核实词频、过滤规则、权重及字号映射；若无可核查的数值，不把大字描述为已证实的高频。
3. 明确“图像事实 / 统计推断 / 设计建议”，总结有效方法和反例，并按证据更新已有的编目型概念说明。
